# Yield Vault

A decentralized yield-generating vault built on the Stacks blockchain.

## Overview

This project implements a secure vault contract that allows users to deposit STX and earn yield through automated investment strategies.

## Features

- 🔒 Secure STX deposits and withdrawals
- 💰 Automated yield generation
- 🔄 Transparent investment strategies
- ⚡ Low-cost transactions

## Installation

```bash
npm install
```

## Configuration

Create environment-specific settings files:
- Mainnet.toml
- Testnet.toml

## Development

```bash
# Run tests
npm test

# Deploy to testnet
npm run deploy:testnet

# Deploy to mainnet 
npm run deploy:mainnet
```

## Security

- All smart contracts are thoroughly tested and audited
- Implements secure deposit/withdrawal patterns
- Access controls for administrative functions
